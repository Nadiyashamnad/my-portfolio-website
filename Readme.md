# Personal Portfolio Website

## 1. Brainstorming & Planning
* **Objective:** Build a responsive, accessible personal portfolio website to display projects, technical skills, and creative UI/UX capabilities[cite: 1].
* **Core Goal:** Present an organized, professional digital presence with smooth interactions and clear section navigation[cite: 1].

## 2. Research & Ideation
* Focused on modern web design practices: responsive layout grids, high contrast for legibility, and fast load times.
* Selected core front-end stack (HTML5, CSS3, JavaScript) to ensure lightweight code without heavy framework dependencies[cite: 1].

## 3. Design Process
* **Visual Hierarchy:** Structured sections intuitively—Hero/Header, About Me, Skills, Projects, and Contact[cite: 1].
* **UI/UX Considerations:** Added smooth scrolling, hover feedback on buttons, and clean spacing for an optimal user experience across desktop and mobile devices[cite: 1].

## 4. Development Workflow
* **`index.html`**: Structured semantic markup for accessibility and search friendliness.
* **`style.css`**: Handled layout design, custom styling, responsive media queries, and color schemes.
* **`script.js`**: Added dynamic frontend functionality and interactive UI elements.
* **Version Control:** Managed source code using Git and published through GitHub[cite: 1].

## 5. AI Tools Used & Contributions
* **Brainstorming & Structure:** Used AI assistance for structuring documentation and refining CSS layouts[cite: 1].
* **Debugging & Refinement:** Assisted in resolving syntax and terminal path issues during Git configuration[cite: 1].
* **Human Ownership:** All design decisions, code customization, and styling choices were manually integrated and verified[cite: 1].

## 6. Testing & Debugging
* Tested layout responsiveness across multiple browser screen sizes (Mobile, Tablet, and Desktop)[cite: 1].
* Verified smooth scrolling behavior, link navigation, and script functionality[cite: 1].
